# FARLine

Line-level defect prediction for cross-version and cross-project settings.

## Environment

Python 3.12.3 with PyTorch 2.8.0 (CUDA 12.8).

## Dataset

The experiments use the LineDP dataset. Place the raw files as follows:

```
dataset/linedp/
├── File-level/                 # <release>_ground-truth-files_dataset.csv
├── Line-level/                 # <release>_defective_lines_dataset.csv
├── handcrafted_features/       # <release>_ast_features.csv, one per release
└── preprocessed_data/          # generated by the preprocessing script
```
